# FloodOps native UI

The public root exports native controls/fields/image picker/badges, Card/MetricCard/Alert/Skeleton/Toast, Dialog/Sheet/Tabs/Tooltip, Form/ErrorSummary, AccessibleList/KeyValueList, and the same context/map/plan/report/review/point/event/result/confirmation presentation families as ui-web. Import `FoundationsGallery` from `@floodops/ui-native/gallery` for the ExpoMobile-owned safe-area development screen. Gallery is excluded from the production root. Reviewed peers are React 19.3/RN 0.88.1/SVG 15.16/Expo 58; no DOM/ARIA/Radix/web imports or app-to-app imports are used.

UI-only presentation types live beside semantic vocabulary in `@floodops/design-tokens`; they are not wire DTOs or schemas. Feature facades adapt frozen contracts and own auth, native photo permissions, API mutations, session replacement/rejoin and secure credential storage. Components do not fetch, read a clock, derive passability/confidence/rewards, optimistically commit or execute domain state. Null values remain Unavailable; zero stays zero. Projected/committed, Simulation, Simulated points, explicit vehicle scope, calibration failed/incomplete and event sequence are visible.

Controls use platform labels/roles/states, scalable text, 48dp targets and keyboard focus styling. Required fields share one visible/linked/explicit accessible name; hints include errors. Disabled reasons cannot be blank. Pending prevents activation. Typed refs reach host controls/inputs. ImagePickerField exposes selected count/removal and calls onPick; the consumer supplies Expo permissions/selection and the server validates/normalizes media. It neither acquires camera permission nor previews raw URI/blob data.

Dialog/Sheet use native Modal, a labelled heading/description, scrollable content and keyboardShouldPersistTaps=handled. Focus targets the title or supplied initial ref, then the return ref on dismissal. ConfirmationControl starts at Cancel, guards current disabledReason and duplicate confirmation, blocks back/cancel during a deadline-bounded pending callback, displays a safe failure and restores trigger focus, with a readable fallback when capability disabled the trigger. ResetControl explains new-session/rejoin behavior; it does not implement Reset or credentials.

SelectField opens labelled radio choices in a sheet, explains unavailable choices and restores the trigger ref. Tabs expose selected/disabled state and only the selected content. Native help opens on focus/press, stays open on focused activation, and has an explicit dismiss button. Form/ErrorSummary requests native accessibility focus after submissionKey changes and may focus specific fields; ReportForm forwards aggregate errors, validates an optional required caption and preserves values. Manual ReviewDecision has no dependency on AI advisory completion.

AccessibleList keeps labelled values readable without a clipped horizontal table; error/loading/empty states are distinct. Maps render the same validated structured geometry/styles as web with native Svg/Path only, explicit scale/vehicle scope, outer state/inner route contrast and a nonspatial segment/marker list. SVG internals stay hidden from AT; markers become actions only with a callback. Source freshness and all status interpretation come from the authoritative consumer.

Run `bun run --cwd packages/ui-native test --watchman=false` and package typecheck. Jest-expo/RNTL renders actual components/SVG adapters with mocked native bridges; this is not physical iOS/Android/VoiceOver/TalkBack proof. Use the public gallery on both platforms for later safe-area, keyboard/switch, text scaling and screen-reader acceptance. No app/device/security/release gate is self-published. Known Expo CLI Zod 3 high/deepmerge low remain disclosed.

Every public prop/token breaking change needs a coordinated consumer migration and approved receipt/version. Keep native/web semantics aligned through shared presentation models and tokens; do not fork schemas, copy primitives into apps or import private package internals. Original SVGs retain internal-use licensing notices; no external artwork-distribution approval is implied.
