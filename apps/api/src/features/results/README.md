# M1 workspace projections

`createWorkspaceViews(ports)` exports the existing registry view names `snapshot`, `overview`, `driver-dashboard`. Lead merges them into the same SessionDO registry already serving SessionRouter; no new HTTP paths or request DTOs. Contributor dashboard remains Review-owned.

`WorkspaceProjectionPorts<State>` uses public `SimulationPersistence` and synchronous canonical DTO facades for clock, knowledge, operations, impact, planning state, committed routes, current reports and coverage. Every callback receives the same deeply frozen server context. Never combine separate RPC reads or import private Planner state. Missing required callbacks, unavailable values and dangling latest pointers fail CONFIG_INCOMPLETE. Scenario comes from the actual persisted immutable simulator bundle; session/generation/time/H/config match that bundle. Marker must be m1-v1/0.5.0-m1. Legacy data is retained and requires explicit Reset/new session, never defaulted or migrated here.

Example Lead ports use public simulation.registry.views[CLOCK_VIEW], public planning.registry.views['planning.operations'/'planning.impact'/'planning.state'/'planning.routes'], public Source scopedKnowledge/currentKnowledge/coverage and sourceState. Parse public view results at the adapter. Planning returns its canonical plans/jobs (including needs_replan normalization); select actual pointers and cross-check linked IDs. Do not always return null for real pointers. Report callback returns only `{generation,report}` records; it must never expose stored submitter/media/digest internals to the client.

Dispatcher snapshot includes actual clock/job, scenario, knowledge, operations, impact, linked latest plan/job, results and graph hash. Viewer overview returns only session/scenario/coverage/results. Driver is server bound to one entity; dashboard filters committed FloodOps orders and active route IDs plus exact participant/current-generation reports. Routes may already be driver-scoped by the public Planner projection. Duplicate route IDs or missing owned committed routes while the driver has a route/stops fail closed. Route.status=candidate is a canonical route shape, not an unexecuted-state signal.

Local Workerd tests compose genuine available Source/Simulator/Planner public facades. Explicit synthetic M1 report records are only privacy fixtures while the Source receipt producer migration is pending; these are not proof of report submission/manual review/points/Execute E2E. No required producer is replaced with an always-empty fleet or fabricated latest plan. Actual planner job serialization and full receipt/review producer cutover remain their owners' work.
